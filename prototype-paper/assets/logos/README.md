# Logos of the approving bodies

Put each body's official logo here, named by its key. SVG is best; a PNG or
WebP with a transparent background also works. Rebuild with `node build.mjs`.

| Key | Body |
|---|---|
| `nwc` | National Water Company |
| `sca` | Saudi Contractors Authority |
| `sec` | Saudi Electricity Company |
| `aramco` | Saudi Aramco |
| `maaden` | Ma'aden |
| `rcjy` | Royal Commission for Jubail and Yanbu |
| `momah` | Ministry of Municipal and Rural Affairs and Housing |

Use only the files the bodies publish; never redraw or recolour a logo. Until a
file is here, the body's name shows in its place.
