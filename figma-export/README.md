# تصدير نموذج SACC إلى Figma

نسخ HTML ثابتة من النموذج التفاعلي (`source/sacc-prototype.html`) جاهزة للاستيراد إلى Figma
بأداة `html_to_figma` (خادم Figma MCP)، لتصبح طبقات قابلة للتعديل وليست صورًا.

النطاق: 10 صفحات × لغتان (العربية RTL / الإنجليزية) × عرضان (سطح المكتب 1440 / الجوال 390) = 40 إطارًا.

## الحالة

ملف Figma: [SACC Website — Prototype](https://www.figma.com/design/BIe4GLH2gzW4DTfVpZkSf4)
(خطة Starter تسمح بـ 3 صفحات فقط، لذلك فيه صفحتان: `العربية (AR)` و `English (EN)`).

| المجموعة | الحالة | الصفحة في Figma |
|---|---|---|
| العربية — Desktop 1440 (10) | **رُفعت** | `العربية (AR)` — `0:1` |
| العربية — Mobile 390 (10) | لم تُرفع — `html/ar-390/` | `العربية (AR)` — `0:1` |
| English — Desktop 1440 (10) | لم تُرفع — `html/en-1440/` | `English (EN)` — `1:4` |
| English — Mobile 390 (10) | لم تُرفع — `html/en-390/` | `English (EN)` — `1:4` |

توقف الرفع عند حد استدعاءات Figma MCP في خطة Starter
(`You've reached the Figma MCP tool call limit on the Starter plan`).

معرّفات الإطارات العربية (Desktop) المرفوعة:

| الصفحة | Node |
|---|---|
| الرئيسية | `7:2` |
| من نحن | `8:2` |
| الخدمات | `9:2` |
| المشاريع | `10:2` |
| المعدات | `11:2` |
| الشهادات | `12:2` |
| المسيرة | `13:2` |
| القيادة | `14:2` |
| تواصل | `15:2` |
| انضم إلينا | `16:2` |

### ما بقي

1. رفع الإطارات الثلاثين في `html/`.
2. ترتيب الإطارات الأربعين على الصفحتين وتسميتها: لم تُرتّب الإطارات المرفوعة ولم تُسمَّ، وقد تكون فوق بعضها.
3. مشكلتان ظهرتا في إطار الرئيسية (`7:2`) ولم تُعالجا:
   - أرقام العمق (0.0 م، ‎-1.0 م …) على يمين المقطع العرضي لا تظهر في Figma.
   - أيقونتا البريد والهاتف في الشريط العلوي تظهران مشوّهتين.
4. لم تُفحص بصريًا في Figma إلا الرئيسية؛ الصفحات التسع الأخرى رُفعت دون فحص بصري هناك.

## طريقة الرفع

لكل ملف: استدعاء `html_to_figma` مع `cssSelector: "body"` و `nodeId` صفحة الهدف
(`0:1` للعربية، `1:4` للإنجليزية)، ثم إرسال الملف إلى رابط `submitUrl` الذي يعيده
(رابط لمرة واحدة، صالح ساعة):

```bash
figma-export/tools/upload.sh figma-export/html/ar-390/home-390.html "<submitUrl>"
```

يتطلب السماح بالنطاق `mcp.figma.com` في إعدادات شبكة البيئة.

## إعادة التوليد والتحقق

```bash
figma-export/tools/build.sh
```

يولّد الملفات الأربعين في `figma-export/build/` (المجلد `html/` لا يُستبدل). الناتج مطابق
بايتًا ببايت للملفات المحفوظة وللملفات العشرة المرفوعة.

التحقق بالمقارنة بكسلًا ببكسل مع النموذج الحي (يحتاج Pillow و numpy):

```bash
cd figma-export/tools && node verify.js <path>/index.html ../html <shots-dir> && python3 verify.py <shots-dir>
```

حيث `index.html` نسخة من `source/sacc-prototype.html` بجانبها مجلد `assets/` من جذر المستودع.

## ما يفعله التحويل (`tools/snap.js` و `tools/prep.js`)

يفتح كل مسار بـ Playwright، ثم يعدّل الـ DOM بحيث يبقى ما يرسمه المتصفح كما هو، ويتحقق من
مواضع كل العناصر قبل التعديل وبعده:

- تثبيت `@media` ووحدات `vw` على العرض المستهدف، وتثبيت عرض الصفحة.
- RTL: auto layout في Figma لا يدعم الاتجاه من اليمين لليسار، فتُعكس صفوف flex العربية إلى
  صفوف LTR بترتيب معكوس (أو `row-reverse`، أو تعويض `vertical-align` حين يتغير خط الأساس)،
  وتُقسَّم الصفوف الملتفّة متعددة الأسطر إلى صف لكل سطر.
- SVG: أبعاد صريحة، والأنماط المحسوبة تُكتب كسمات، وحذف الطبقات غير المرئية.
- الحلقات `box-shadow: inset` تتحول إلى `border` مع إنقاص الـ padding بالمقدار نفسه.
- الخط المتقطع (`repeating-linear-gradient`) يُرسم كـ SVG.
- الصور المحلية تُضمَّن كـ data URI، وتُحذف السكربتات.

### الفروق المعروفة عن النموذج

- ملمس طبقات التربة في المقطع العرضي (`<pattern>`) صار لونًا واحدًا هو لون أساس كل نمط،
  لأن Figma لا يدعم تعبئة SVG بالأنماط.
- زر «اختر ملفاً» في صفحة انضم إلينا منزاح 1.3 بكسل.
- بضع بكسلات متفرقة (1–6) في صفحات الشهادات وتواصل وانضم إلينا (الإنجليزية).
