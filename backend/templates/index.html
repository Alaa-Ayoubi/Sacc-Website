SACC Backend

Content and form handling for the Sana Al-Awael Contracting website.

This is not the public website. It is the service behind it — the admin where content is edited, and the API that receives quote requests and job applications. The website itself is published separately.

Endpoints

GET /api/v1/site/ All content, both languages. ?lang=ar or ?lang=en for one.
GET /api/v1/projects/ Portfolio. ?category=water, ?lang=ar.
GET /api/v1/careers/openings/ Open roles.
POST /api/v1/leads/quote-requests/ Quote request form.
POST /api/v1/careers/applications/ Job application, with optional CV upload.
GET /api/v1/health/ Liveness, including the database.
